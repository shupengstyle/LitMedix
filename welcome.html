新增 · 文献管理软件导出

把文献带入你的文献库

在 PubMed 检索结果页或文章详情页，点击指标栏旁的“引用”，选择对应软件。

EndNoteZoteroNoteExpress
  1. 选择导出格式点击“导出至 EndNote / Zotero / NoteExpress（RIS）”。
  2. 下载完整题录插件从 PubMed 获取作者、卷期、页码、DOI、摘要等可用信息，生成 .ris 文件。
  3. 导入文献库打开下载的文件，或在软件中选择“文件导入”。Zotero 选择该文件；EndNote 选择 Reference Manager (RIS)；NoteExpress 选择 RIS 过滤器。

是否自动打开软件取决于电脑的文件关联设置。导出的是文献题录，不包含全文 PDF；获取题录需要联网。

再试试这些阅读工具

相似文献：在详情页点击“加载相似文献”，按已导入的期刊 IF 排序查看。

关键词高亮：在筛选框“更多筛选”中输入标题关键词，筛选并高亮命中词。

保存检索式：在 PubMed 检索结果页打开扩展弹窗，点击“保存当前页”，下次可直接复用。
